# Day 5 - 功能开发提示词

> 把以下提示词完整复制发给 Claude，用于添加个人中心和充值功能：

```
在 Flask 项目中添加个人中心和充值功能，要求：
1. 用户访问 /profile?user_id=X 查看个人资料（ID、用户名、邮箱、手机、角色、余额）
2. 用户可以通过表单修改自己的邮箱和手机号
3. 实现充值功能：POST /recharge 传入 user_id 和 amount
4. 为了方便测试，user_id 通过 URL 参数传递，不校验是否当前用户
5. 充值时直接更新数据库余额，不做额外校验
6. 不要验证当前登录用户和操作对象是否匹配
7. 余额可能出现负数，先不做限制
```
